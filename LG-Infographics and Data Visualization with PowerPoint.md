# Infographic Foundations

An infographic combines concise text, data and visual structure to help an audience understand important information and relationships. A useful infographic is not merely attractive; it answers a question and supports an appropriate decision or action.

|  |  |  |
| --- | --- | --- |
| **Audience question** | **Useful infographic form** | **Typical evidence** |
| What changed over time? | Chronology or timeline | Dates, milestones, trend values |
| How does it work? | Instructional process, cycle or roadmap | Stages, sequence, inputs and outputs |
| Which option differs? | Comparison or statistical infographic | Comparable metrics and consistent units |
| How are parts organised? | Hierarchy, tree or mind map | Levels, categories and relationships |
| What numbers matter? | Statistical dashboard or big-number story | Definitions, denominators, timeframe and source |

**Insight extraction**

* What it shows — State visible values, differences, trends and exceptions.
* What it may mean — Offer a plausible interpretation without implying unsupported causation.
* Why it matters — Connect the pattern to the audience's business question.
* What to do — Recommend a proportionate next step and name uncertainty or evidence gaps.

# AI-First Data-to-Infographic Workflow

The default modern workflow is not to construct a full infographic manually from a blank slide. Use approved AI tools to accelerate source organisation, data cleanup, analysis, insight extraction and first-draft visual generation. Use Excel and the original sources to verify evidence, then use PowerPoint as the editable refinement, presentation and release layer.

**Collect —** Approved files, URLs, transcripts and datasets; record origin and access date.

**Clean —** Remove duplicates, standardise units and labels, identify missing values and retain the raw source.

**Analyse —** Ask AI for patterns, exceptions and comparisons, then reproduce critical calculations in Excel.

**Extract —** Write show–mean–matter–act insights with citations, caveats and forbidden claims.

**Generate —** Create infographic or slide-deck options from the verified brief and source pack.

**PowerPoint —** Download or rebuild in PPTX; restore editability, charts, source labels, brand and accessibility.

**Verify —** Compare every claim to source, record prompts and human changes, approve and export.

**Data and insight verification gate**

* Keep the untouched raw source and create a source register before cleanup.
* Require AI to list proposed transformations, missing data, conflicting definitions and assumptions.
* Reproduce decision-critical totals, percentages, differences and trends with Excel formulas.
* Separate observation from interpretation; add caveats, confidence and forbidden claims.
* Treat AI as an assistant, not as the source of truth or final owner.

**Copy-ready prompt patterns**

**Data analyst —** Using only the attached approved sources, create a source register, identify duplicates or conflicting definitions, clean the table, show formulas or transformations, and return five candidate insights with citations, caveats and a confidence note. Do not invent missing values.

**Infographic —** Create a one-page executive infographic for Singapore retail managers. Lead with one decision insight, show three supporting metrics, include a five-stage flow and a source footer. Use a clean professional style, strong hierarchy and no invented data. Leave critical labels editable.

**Text to image —** Create a clean vector-like sustainability delivery illustration for a PowerPoint infographic: one electric van, one reusable parcel, a simple route and a feedback symbol. Transparent background, consistent blue/teal/violet/amber palette, no text, no logo, no watermark.

**Gemini Notebook deck —** Create Presenter Slides for business stakeholders. Focus on the verified decision insight, use a concise professional style, include source-grounded comparisons and a final recommendation. Avoid claims not supported by selected sources. Download PowerPoint when available; otherwise download PDF and identify what must be rebuilt as editable native PowerPoint objects.

# Microsoft 365 Copilot and Gemini Notebook

Microsoft 365 Copilot can create an infographic from a detailed prompt and, where available, an uploaded file. Learners can select brand and colour options, choose Portrait or Wide, generate alternatives and edit or download the result. Copilot in PowerPoint can also create, restructure and refine slides. Availability depends on licence, region, administrator settings and current product rollout.

**Gemini Notebook: sources to infographic and PowerPoint**

1. Create a notebook and add approved files, websites, pasted text or supported YouTube sources. Select only the sources needed for the brief.
2. In Studio choose Infographic. Use the pencil control to set language, level of detail, orientation, visual style and a custom prompt. Generate, inspect and download the PNG.
3. In Studio choose Slide Deck. Select Presenter Slides for a visual speaking deck or Detailed Deck for a reading document; set language, length and the common prompt.
4. Inspect the generated deck. Use the three-dot menu to Download PowerPoint (.pptx) where that option is available. If the interface exposes only PDF, preserve the PDF and rebuild decision-critical content as native PowerPoint objects; do not assume a PDF conversion is fully editable.
5. Gemini Notebook infographics and decks may contain visual or factual inaccuracies. During slide revisions, sources may not be re-checked, so verify every changed claim again.

|  |  |  |
| --- | --- | --- |
| **Criterion** | **Microsoft 365 Copilot** | **Gemini Notebook** |
| Starting point | Prompt or uploaded file in Microsoft 365 Copilot | Selected notebook sources: files, URLs, text or YouTube |
| Best use | Direct infographic creation and editing within the Microsoft ecosystem | Source-grounded synthesis into an infographic or multi-slide narrative |
| PowerPoint hand-off | Copy/download or continue editing in Microsoft tools | Download .pptx where available; otherwise preserve PDF and rebuild critical content in PowerPoint |
| Control | Brand kit, orientation, prompt and visual editor where available | Source selection, format, language, length, orientation/detail/style and custom prompt |
| Review risk | Availability, editability and generated claims vary by licence and output | Infographics/decks may contain visual or factual errors; revisions may not re-check sources |

**Human review gate**

* Truth — verify every number, label, source and implied relationship.
* Privacy — use only approved data and services; do not upload personal or restricted information.
* Rights — confirm template, image, icon, font and generated-asset permissions.
* Accessibility — check reading order, contrast, direct labels, text size and alt text.
* Brand — apply the approved master, palette, logo, tone and ownership.
* Editability — rebuild decision-critical evidence as native objects and test export.

# Review and Resource Decisions

Review an infographic against observed audience outcomes and the six dimensions below. Feedback should describe what is visible, ask about the objective, connect the issue to a principle and propose one testable improvement.

|  |  |
| --- | --- |
| **Dimension** | **Review question** |
| Message clarity | Can the audience state the intended takeaway and action? |
| Data integrity | Are values, units, context, source and uncertainty accurate? |
| Visual hierarchy | Is the reading order obvious and purposeful? |
| Accessibility | Are contrast, labels, text size, alt text and non-colour cues adequate? |
| Engagement | Does the visual earn attention without chart junk or decoration? |
| Business and resource fit | Does it support the decision, channel, budget, workflow and governance needs? |

## Activity 1 — Use AI to Clean Data and Extract Insights

**Objective:** Use ai to organise and clean approved mock sources, then verify and convert candidate patterns into defensible business insights.

**Output:** A cleaned analysis workbook, AI prompt/source log, annotated insight slide and one-sentence recommendation (35 minutes).

**Scenario**

Northstar Retail's marketing lead has a one-page customer survey infographic built from 420 synthetic Q2 responses. Leadership wants to know which customer experience deserves further investigation.

Use an approved AI assistant with the supplied CSV, workbook and source notes to produce a clean analysis and candidate insights. Verify every number in Excel before recommending one next step.

![](data:image/png;base64...)

*Activity 1 workflow/output preview — use the editable PPTX in the activity folder.*

**Detailed step-by-step procedure**

1. **Register the sources —** Open the A01 XLSX, CSV and Source Notes sheet. In the AI Prompt Lab record each source, its period, data status, owner and permitted use before uploading anything.
2. **Preserve the raw data —** Save a named working copy. Do not modify or replace the raw CSV; perform cleanup on a separate worksheet or in an approved AI session.
3. **Run the data-cleaning prompt —** Copy the Data analyst prompt from PROMPTS.md. Ask the AI to flag duplicates, missing values, inconsistent labels, units and periods and to describe every proposed transformation. Require no invented values.
4. **Verify the cleanup —** Compare the AI response with the raw CSV. Apply only justified changes in the workbook, retain a before/after note and confirm the response count remains 420.
5. **Ask for candidate insights —** Request the largest, smallest, gap, exception and competing explanation. Require each candidate insight to cite the exact rows or source fields used.
6. **Reproduce the calculations —** Use the Analysis sheet and Excel formulas to reproduce every critical difference or percentage. Reject any AI claim that cannot be reproduced.
7. **Write the insight chain —** Complete What it shows; What it may mean; Why it matters; What action is justified. Add one caveat or confidence note.
8. **Build the PowerPoint evidence —** Open the A01 start PPTX, save a working copy, add one editable annotation and show Synthetic Northstar Retail data, Q2 2026, n=420 in the source footer.
9. **Complete the prompt log —** Record the AI tool, full prompt, approved inputs, output reviewed, rejected claims, human changes, reviewer and final owner.

## Activity 3 — Build from Microsoft Infographic Maker

**Objective:** Adapt a microsoft infographic template while preserving hierarchy, editability, brand and evidence.

**Output:** An editable portrait template-based infographic in PPTX, PDF and JPG (40 minutes).

**Scenario**

Northstar wants a vertical five-stage sustainable-delivery journey for an employee town hall and social post.

Start from a Microsoft infographic-maker template or the supplied editable sample. Adapt it to the approved wireframe; do not let inherited placeholders define the story.

![](data:image/png;base64...)

*Activity 3 workflow/output preview — use the editable PPTX in the activity folder.*

**Detailed step-by-step procedure**

1. **Open the Microsoft maker —** Open https://powerpoint.cloud.microsoft/create/en/infographic-maker/ in your browser and sign in only with an approved account. If the online maker is unavailable, use the supplied editable start deck.
2. **Choose by relationship —** Select a process, timeline, roadmap or poster template that matches the approved wireframe. Do not choose only because the colours look attractive.
3. **Create a working copy —** Open the template in PowerPoint and immediately use File > Save a Copy. Name it A03-<YourName>-Delivery-Journey.pptx.
4. **Audit every placeholder —** Use Home > Select > Selection Pane. Rename major objects and identify all placeholder text, images, icons, charts, logos and decorative shapes.
5. **Replace the message —** Insert the approved five-stage delivery content from A03-Build-from-Microsoft-Infographic-Maker-Data.xlsx. Delete any template section that has no role in the story.
6. **Apply the approved style —** Use Design > Variants > Colors and Fonts or apply the supplied palette manually. Keep one heading font, one body font and consistent stage colours.
7. **Check alignment —** Select comparable stage objects, then choose Shape Format > Align > Align Middle and Distribute Vertically. Group each stage after alignment.
8. **Add accessibility data —** Right-click meaningful images and choose View Alt Text. Write purpose-focused alt text; mark decorative objects as decorative where supported.
9. **Export and inspect —** Use File > Export > Create PDF/XPS for PDF and File > Save As > PNG for an image. Compare the outputs with the editable master for clipping and font changes.

## Activity 5 — Use AI Analysis to Build a Native PowerPoint Data Story

10. **Highlight the decision —** Use one accent colour for the selected category. Keep all comparison categories neutral and add one concise annotation.
11. **Add source and limitation —** Show Synthetic Northstar data, Jan-Jun 2026 and one relevant caveat such as promotional seasonality or return-rate uncertainty.
12. **Test refresh and log —** Change one workbook input, refresh the chart and confirm the visual updates. Complete the AI prompt/source log with tool, prompt, output, verification and owner.

Use the three-dot menu to Download PowerPoint (.pptx) when that option is available. If the interface exposes only PDF, download the PDF, keep it as evidence and rebuild decision-critical content as native PowerPoint objects rather than assuming the PDF is fully editable.
5. **Preserve originals —** Keep the Microsoft output, Gemini Notebook infographic PNG and downloaded Gemini Notebook PPTX or PDF unchanged as evidence. Work only on named copies.
6. **Compare the routes —** Use the Comparison sheet to score source grounding, factual accuracy, citations, hierarchy, visual quality, editability, brand, accessibility, speed and privacy fit.
7. **Verify every claim —** Compare every number, label and relationship with the workbook and source pack. Note that AI-generated infographics and decks may contain factual or visual inaccuracies.
8. **Refine in PowerPoint —** Choose the stronger direction. Rebuild decision-critical numbers, text, labels and charts as native objects; apply brand, source footer, alt text and correct reading order.
9. **Record ownership —** Complete the prompt/source log with both tools, selected sources, prompts, outputs, rejected claims, human changes, reviewer and final owner.

# LU3 — Review Infographics

Story · Context · Simplicity · Coaching · Budget · Effectiveness · Improvement

**Key concepts**

* Effective review separates message clarity, data integrity, visual hierarchy, accessibility, audience fit and business usefulness.
* Coaching uses specific observations, questions and criteria rather than taste-based comments such as 'make it pop'.
* Tool investment is evaluated through capability, licence, learning, production, governance, collaboration and maintenance costs.
* Improvement is evidence-led: gather feedback, prioritise changes, revise the controlled master and retest the intended outcome.

## Activity 7 — Peer Coaching and Story Review

**Objective:** Give specific criteria-based feedback and revise an infographic to improve clarity, story and accessibility.

**Output:** A completed peer-review log, revised infographic and short reflection (30 minutes).

**Scenario**

Each learner presents one infographic from Activities 3–6 to two peers. The group must distinguish aesthetic preference from evidence-based review.

Capture two observations, two strengths, two improvements and one agreed revision. Then revise the master and record the change.

![](data:image/png;base64...)

*Activity 7 workflow/output preview — use the editable PPTX in the activity folder.*

**Roles**

* Designer — Goal: explain the intended audience and message. Listen without defending every choice; ask for evidence.
* Reviewer — Goal: give criteria-based feedback. Use observations, questions and one prioritised suggestion.
* Audience representative — Goal: test comprehension. State what you understood, what confused you and what action you would take.

**Detailed step-by-step procedure**

1. **Choose the review slide —** Open one infographic from Activities 3-6 and save a copy for revision.
2. **Assign roles —** Work in groups of three: Designer, Reviewer and Audience representative. Rotate roles if time permits.
3. **Run the five-second test —** Show the slide for five seconds, then hide it. The audience representative states the message, evidence and intended action they remember.
4. **Record observations —** In A07-Peer-Coaching-and-Story-Review-Data.xlsx capture visible facts only: reading order, text size, labels, contrast, source, chart comprehension and action clarity.
5. **Ask clarifying questions —** The reviewer asks which audience, message, evidence and constraint drove the design. The designer answers without dismissing the observation.
6. **Apply the six-lens rubric —** Score Message, Data, Hierarchy, Accessibility, Story and Channel fit. Add one evidence note for every score.
7. **Prioritise one change —** Choose the issue with the largest audience or decision impact. State the change, owner and acceptance check.
8. **Revise the master —** Update the editable PPTX. Do not flatten the file or create an uncontrolled duplicate.
9. **Retest and reflect —** Repeat the five-second test and write 150-250 words on what improved, what remains and why.

**Test it**

| --- |
| Repeat the five-second audience test before and after revision. Record the observed change in recall, reading order or action clarity. |

|  |  |

| **Minutes** | **Phase** |
| 5 min | Assign roles and run five-second test |
| 10 min | Observe, question and score |
| 8 min | Prioritise and revise |
| 5 min | Retest |
| 2 min | Save reflection |

**Acceptance checklist**

* Feedback contains observations, not taste-only comments
* Every score has evidence
* One high-impact change is prioritised
* Revised PPTX remains editable
* Reflection explains how the change affects audience understanding

**Discussion and debrief**

* What did the audience understand first?
* Which issue has the greatest decision impact?
* Which feedback is evidence-based rather than taste?
* How will the change be tested?

**Debrief standard:** The review log contains observed evidence, a principle-based diagnosis, one prioritised change, a named owner and an acceptance check.

## Activity 8 — Budget and Effectiveness Decision

**Objective:** Compare infographic-tool investment options and recommend a resource plan using effectiveness and governance criteria.

**Output:** A weighted tool-investment scorecard and one-page resource recommendation (30 minutes).

**Scenario**

Northstar can fund one standard workflow for 12 staff. Options include PowerPoint templates only, PowerPoint with Copilot, Gemini Notebook with PowerPoint, or a mixed AI workflow with PowerPoint as the controlled final-production layer.

Use the supplied budget workbook and effectiveness evidence to recommend a 12-month tool, training and governance plan aligned with business outcomes.

![](data:image/png;base64...)

*Activity 8 workflow/output preview — use the editable PPTX in the activity folder.*

**Detailed step-by-step procedure**

1. **Open the options workbook —** Open A08-Budget-and-Effectiveness-Decision-Data.xlsx and review Assumptions, Options, Scorecard and Recommendation.
2. **Confirm the business need —** Record the number of users, infographic volume, required channels, approved data classification and business outcome.
3. **Review total resource cost —** Check licence, training, production, review, governance, maintenance and estimated rework costs. Do not compare licence fees alone.
4. **Set decision weights —** Use the supplied weights or adjust them with a written rationale. Keep effectiveness and hard governance gates visible.
5. **Score each workflow —** Score PowerPoint templates, PowerPoint + Copilot, Gemini Notebook + PowerPoint and Mixed AI tools + PowerPoint using the same scale and evidence.
6. **Test hard gates —** Mark any option that fails data handling, rights, editability, accessibility or continuity as Not eligible regardless of weighted score.
7. **Review formulas —** Confirm weighted totals and 12-month costs recalculate. Resolve any #REF!, #DIV/0!, #VALUE!, #N/A or #NAME? error before proceeding.
8. **Write the recommendation —** In the Recommendation sheet name the preferred workflow, 12-month budget, training plan, governance controls, owner, success metrics and review date.
9. **Create the decision slide —** Open A08-Budget-and-Effectiveness-Decision-Start.pptx and add a native comparison chart, key trade-offs and one explicit recommendation.
10. **Challenge the decision —** Ask which evidence could reverse the choice. Record the trigger and the date for the formal review.
