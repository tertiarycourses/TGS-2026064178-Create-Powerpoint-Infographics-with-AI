# Activity 03 — Copy-Ready Microsoft 365 Copilot Prompts

Use these prompts with only approved or synthetic inputs. Replace bracketed details, keep a copy of the submitted prompt, and verify every output against the source pack.

## Structured infographic prompt

```text
Create a one-page timeline infographic about Create a Timeline Infographic with Microsoft 365 Copilot.
Sections:
1. Purpose
2. Content
3. Hierarchy
4. Brand
5. Access
Audience: people managers
Decision: The final template-based infographic is message-led, branded, accessible, source-labelled and fully editable.
Style: professional, concise, high contrast and accessible
Format: Wide for PowerPoint unless the brief requires Portrait
Source rule: use only the attached approved or synthetic course data; include period and source; do not invent facts
```

**Verification:** Check every section, claim, number, relationship, source, reading order and accessibility decision before PowerPoint release.

## Analyse the evidence

Using only the attached approved source, identify the three strongest patterns, the denominator for each metric, one limitation and one proportionate business action. Cite the source field or row for every number. Do not invent missing values or imply causation.

**Verification:** Record sources used, claims checked, rejected output, human changes, reviewer and owner.

## Create the infographic

Create a one-page [TYPE] infographic about [TOPIC]. Sections: 1. [SECTION ONE] 2. [SECTION TWO] 3. [SECTION THREE] 4. [SECTION FOUR] 5. [SECTION FIVE]. Audience: [AUDIENCE]. Decision: [DECISION]. Style: professional, high contrast, concise, accessible and aligned to [BRAND]. Use only the approved attached content. Include source and period. Do not invent data.

**Verification:** Record sources used, claims checked, rejected output, human changes, reviewer and owner.

## Refine in PowerPoint

Turn the selected infographic direction into one editable PowerPoint slide. Keep the action title, labels, numbers, chart or process, source footer and accessibility notes editable. Remove decoration that does not support the message. Apply the approved brand colours and preserve one clear reading path.

**Verification:** Record sources used, claims checked, rejected output, human changes, reviewer and owner.

## Quality review

Review this infographic against message clarity, data accuracy, visual hierarchy, audience fit, accessibility, editability and business goal. List each issue with evidence, its impact, the proposed change and a pass/fail acceptance check. Do not rewrite verified facts.

**Verification:** Record sources used, claims checked, rejected output, human changes, reviewer and owner.

## Prompt anatomy

Infographic type and topic → ordered sections → audience and decision → approved sources and evidence → visual style and format → constraints and forbidden claims → verification and ownership.
