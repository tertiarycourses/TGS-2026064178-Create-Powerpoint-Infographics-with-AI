# Activity 04 — Create a Shape, Icon and SmartArt System

**Course:** Infographics and Data Visualization with PowerPoint (TGS-2024048310)  
**Duration:** 35 minutes  
**Tools:** PowerPoint Shapes, Icons and SmartArt  
**Output:** Five-stage process infographic and reusable PowerPoint component library

## Objective

Build an editable process infographic using alignment, consistent shapes, icons, type and smartart.

## Scenario

Northstar needs an editable five-stage process infographic for store managers. The current draft mixes icons, connector styles and uneven spacing.
Rebuild the process with a reusable stage component, PowerPoint alignment tools and a consistent icon/SmartArt choice.

## Detailed instructions

1. **Open the start file.** Open A04-Process-System-Start.pptx and save a working copy.

2. **Set guides and margins.** Choose View > Guides. Drag guides to define equal side margins and the centre line. Keep all stages inside the safe area.

3. **Build one stage component.** Insert a rounded rectangle, a numbered circle, one icon and a short label. Use Shape Format > Size for consistent dimensions.

4. **Duplicate consistently.** Select the complete stage, press Ctrl+G or Command+G to group it, then duplicate it four times. Edit labels only after the layout is stable.

5. **Align and distribute.** Select all stage groups and choose Shape Format > Align > Align Middle, then Distribute Horizontally.

6. **Add real connectors.** Choose Insert > Shapes > Lines > Connector. Attach connectors to the connection points of each stage so they remain linked when moved.

7. **Use one icon family.** Choose Insert > Icons and search for the five concepts. Apply one outline or filled style consistently and add direct text labels.

8. **Test SmartArt as an alternative.** Duplicate the slide. Choose Insert > SmartArt > Process and recreate the stages. Compare control, speed and editability; retain the stronger version and record why.

9. **Create the component library.** Copy one clean stage, connector, label and icon treatment to a Components slide for future reuse.

## Suggested timing

- 5 minutes — Set grid and build first component
- 15 minutes — Duplicate, align and connect
- 8 minutes — Insert and format icons
- 5 minutes — Compare SmartArt
- 2 minutes — Save and submit
