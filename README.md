# Infographics and Data Visualization with PowerPoint

WSQ courseware for **TGS-2024048310**, aligned to **TOU-DAT-4004-1.1-1**.

![Courseware cover](screenshot.png)

## Package

- 116-slide visual PowerPoint deck and matching PDF
- Detailed Learner Guide in DOCX and PDF
- One-day Lesson Plan in DOCX and PDF
- Eight progressive, self-contained activity folders
- Editable mock CSV, formula-enabled Excel and PowerPoint start/sample files in every activity

## Learning outcomes

1. Draw insights from infographics to make data-driven decisions.
2. Use PowerPoint infographics to articulate data insights to stakeholders.
3. Assess the effectiveness of PowerPoint infographics based on audience outcomes and resource allocation.

## Current PowerPoint workflows

The package covers native PowerPoint shapes, icons, SmartArt and charts; Excel-to-PowerPoint evidence; Microsoft Infographic Maker templates; and AI-assisted PowerPoint design with a human verification gate.

## Repository boundary

This public repository contains learner-facing courseware and activities only. Assessment papers, answer keys, reference material, QA renders, build tooling and environment configuration are deliberately excluded.
