# Infographic Foundations

An infographic combines concise text, data and visual structure to help an audience understand important information and relationships. A useful infographic is not merely attractive; it answers a question and supports an appropriate decision or action.

|  |  |  |
| --- | --- | --- |
| **Audience question** | **Useful infographic form** | **Typical evidence** |
| What changed over time? | Chronology or timeline | Dates, milestones, trend values |
| How does it work? | Instructional process, cycle or roadmap | Stages, sequence, inputs and outputs |
| Which option differs? | Comparison or statistical infographic | Comparable metrics and consistent units |
| How are parts organised? | Hierarchy, tree or mind map | Levels, categories and relationships |
| What numbers matter? | Statistical dashboard or big-number story | Definitions, denominators, timeframe and source |

**Insight extraction**

* What it shows — State visible values, differences, trends and exceptions.
* What it may mean — Offer a plausible interpretation without implying unsupported causation.
* Why it matters — Connect the pattern to the audience's business question.
* What to do — Recommend a proportionate next step and name uncertainty or evidence gaps.

# AI-First Data-to-Infographic Workflow

The default modern workflow is not to construct a full infographic manually from a blank slide. Use approved AI tools to accelerate source organisation, data cleanup, analysis, insight extraction and first-draft visual generation. Use Excel and the original sources to verify evidence, then use PowerPoint as the editable refinement, presentation and release layer.

**Collect —** Approved files, URLs, transcripts and datasets; record origin and access date.

**Clean —** Remove duplicates, standardise units and labels, identify missing values and retain the raw source.

**Analyse —** Ask AI for patterns, exceptions and comparisons, then reproduce critical calculations in Excel.

**Extract —** Write show–mean–matter–act insights with citations, caveats and forbidden claims.

**Generate —** In Microsoft 365 Copilot, choose Create > Design an infographic, describe the output, optionally add approved content, choose brand and orientation, then generate.

**PowerPoint —** Download or rebuild in PPTX; restore editability, charts, source labels, brand and accessibility.

**Verify —** Compare every claim to source, record prompts and human changes, approve and export.

**Data and insight verification gate**

* Keep the untouched raw source and create a source register before cleanup.
* Require AI to list proposed transformations, missing data, conflicting definitions and assumptions.
* Reproduce decision-critical totals, percentages, differences and trends with Excel formulas.
* Separate observation from interpretation; add caveats, confidence and forbidden claims.
* Treat AI as an assistant, not as the source of truth or final owner.

**Copy-ready prompt patterns**

**Analyse the evidence —** Using only the attached approved source, identify the three strongest patterns, the denominator for each metric, one limitation and one proportionate business action. Cite the source field or row for every number. Do not invent missing values or imply causation.

**Create the infographic —** Create a one-page [TYPE] infographic about [TOPIC]. Sections: 1. [SECTION ONE] 2. [SECTION TWO] 3. [SECTION THREE] 4. [SECTION FOUR] 5. [SECTION FIVE]. Audience: [AUDIENCE]. Decision: [DECISION]. Style: professional, high contrast, concise, accessible and aligned to [BRAND]. Use only the approved attached content. Include source and period. Do not invent data.

**Refine in PowerPoint —** Turn the selected infographic direction into one editable PowerPoint slide. Keep the action title, labels, numbers, chart or process, source footer and accessibility notes editable. Remove decoration that does not support the message. Apply the approved brand colours and preserve one clear reading path.

**Quality review —** Review this infographic against message clarity, data accuracy, visual hierarchy, audience fit, accessibility, editability and business goal. List each issue with evidence, its impact, the proposed change and a pass/fail acceptance check. Do not rewrite verified facts.

# Microsoft 365 Copilot Infographic Creation

The Microsoft 365 Copilot app can create an infographic from a detailed description and, where available, approved uploaded content. Learners can choose Brand and color, select Portrait or Wide, generate alternatives, then copy, edit or download the result. Copilot in PowerPoint can add, restructure and refine slide content. Availability depends on licence, region, administrator settings and current product rollout.

**Current Microsoft workflow**

**Describe —** State type, topic, sections, audience, decision, style and source constraints.

**Add content —** Upload only approved content when the feature and policy allow it.

**Brand and color —** Use an approved brand kit or a controlled palette.

**Orientation —** Choose Portrait for one-page reading or Wide for a presentation slide.

**Create —** Generate options, inspect the result and keep the strongest direction.

**Edit or download —** Correct facts, refine hierarchy and bring the accountable master into PowerPoint.

**Structured sample prompt**

The prompt below follows the user-supplied example and adds audience, decision, accessibility and source controls.

Create a one-page process infographic about cybersecurity awareness.

Sections:

1. Common threats

2. Phishing examples

3. Safe password practices

4. Multi-factor authentication

5. Reporting suspicious activity

Audience: office employees

Decision: recognise, avoid and report suspicious activity

Style: professional, high contrast and accessible

Source rule: use only the attached approved policy; do not invent facts

**Prompt anatomy**

|  |  |  |
| --- | --- | --- |
| **Prompt field** | **What to specify** | **Verification question** |
| Type and topic | Timeline, process, comparison, statistical, hierarchy, mind map or scorecard | Does the form match the relationship? |
| Sections | Ordered content blocks with direct labels | Does each section earn space? |
| Audience and decision | Who will use the visual and what they must decide or do | Can the audience state the action? |
| Style and format | Professional, brand, contrast, Portrait or Wide | Does the channel fit the output? |
| Source rule | Approved attachment, period, scope and forbidden claims | Can every claim be traced? |

**Human review gate**

* Truth — verify every number, label, source and implied relationship.
* Privacy — use only approved data and services; do not upload personal or restricted information.
* Rights — confirm template, image, icon, font and generated-asset permissions.
* Accessibility — check reading order, contrast, direct labels, text size and alt text.
* Brand — apply the approved master, palette, logo, tone and ownership.
* Editability — rebuild decision-critical evidence as native objects and test export.

## Activity 1 — Interpret a Statistical KPI Infographic

**Objective:** Interpret a statistical kpi infographic, verify its denominators and convert visible patterns into defensible business decisions.

**Output:** A verified statistical KPI infographic, prompt/source log, annotated insight slide and one-sentence recommendation (35 minutes).

**Scenario**

Northstar Retail's marketing lead has a one-page customer survey infographic built from 420 synthetic Q2 responses. Leadership wants to know which customer experience deserves further investigation.

Use Microsoft 365 Copilot with the supplied approved data summary to propose candidate insights. Verify every number in Excel before recommending one next step.

*Activity 1 workflow/output preview — use the editable PPTX in the activity folder.*

**Detailed step-by-step procedure**

1. **Register the sources —** Open the A01 XLSX, CSV and Source Notes sheet. In the AI Prompt Lab record each source, its period, data status, owner and permitted use before uploading anything.
2. **Preserve the raw data —** Save a named working copy. Do not modify or replace the raw CSV; perform cleanup on a separate worksheet or in an approved AI session.
3. **Run the data-cleaning prompt —** Copy the Analyse the evidence prompt from PROMPTS.md into Microsoft 365 Copilot. Ask it to flag duplicates, missing values, inconsistent labels, units and periods and to describe every proposed transformation. Require no invented values.
4. **Verify the cleanup —** Compare the AI response with the raw CSV. Apply only justified changes in the workbook, retain a before/after note and confirm the response count remains 420.
5. **Ask for candidate insights —** Request the largest, smallest, gap, exception and competing explanation. Require each candidate insight to cite the exact rows or source fields used.
6. **Reproduce the calculations —** Use the Analysis sheet and Excel formulas to reproduce every critical difference or percentage. Reject any AI claim that cannot be reproduced.
7. **Write the insight chain —** Complete What it shows; What it may mean; Why it matters; What action is justified. Add one caveat or confidence note.
8. **Build the PowerPoint evidence —** Open the A01 start PPTX, save a working copy, add one editable annotation and show Synthetic Northstar Retail data, Q2 2026, n=420 in the source footer.
9. **Complete the prompt log —** Record the AI tool, full prompt, approved inputs, output reviewed, rejected claims, human changes, reviewer and final owner.

2. **Run the Copilot route —** In the Microsoft 365 Copilot app choose Create > Design an infographic. Add the approved strategy note where available, submit the hierarchy prompt, choose Wide and apply the approved brand colours.
3. **Generate two directions —** Request two hierarchy alternatives: a top-down tree and a cascading goal-to-owner flow. Preserve both outputs unchanged as evidence.
4. **Score the hierarchy —** Use the workbook to score relationship accuracy, source grounding, hierarchy, editability, brand, accessibility and business usefulness.
5. **Verify every relationship —** Compare every goal, outcome, measure, owner and review statement with the approved source pack. Reject any inferred target or ownership statement that is not supported.
6. **Refine in PowerPoint —** Choose the stronger direction. Rebuild decision-critical text, connectors and levels as native objects; apply brand, source footer, alt text and correct reading order.
7. **Test the chain —** Ask a peer to read from goal to review and explain the logic. Revise any ambiguous connector or level, then export PDF and compare it with the editable master.
8. **Record ownership —** Complete the prompt/source log with selected sources, both Copilot outputs, rejected claims, human changes, reviewer and final owner.

**Test it**

## Activity 7 — Create and Review a Stakeholder Mind Map Infographic

**Objective:** Create a stakeholder mind map, give criteria-based feedback and revise it to improve clarity, story and accessibility.

**Output:** A stakeholder mind map infographic, completed peer-review log, revised PowerPoint and short reflection (30 minutes).

**Scenario**

Each learner uses Microsoft 365 Copilot to draft a stakeholder mind map linking executives, managers, analysts, staff and customers to one common decision story.

Present the editable PowerPoint mind map to two peers. Capture two observations, two strengths, two improvements and one agreed revision, then retest the reading path.

![](data:image/png;base64...)

*Activity 7 workflow/output preview — use the editable PPTX in the activity folder.*

**Roles**

* Designer — Goal: explain the intended audience and message. Listen without defending every choice; ask for evidence.
* Reviewer — Goal: give criteria-based feedback. Use observations, questions and one prioritised suggestion.
* Audience representative — Goal: test comprehension. State what you understood, what confused you and what action you would take.

**Detailed step-by-step procedure**

1. **Generate the mind map —** Use Microsoft 365 Copilot to draft a stakeholder mind map linking executives, managers, analysts, staff and customers to one decision story. Preserve the prompt and generated option.
2. **Create the review slide —** Rebuild the selected mind map as an editable PowerPoint slide, with direct labels, purposeful connectors, a source note and one central decision.
3. **Assign roles —** Work in groups of three: Designer, Reviewer and Audience representative. Rotate roles if time permits.
4. **Run the five-second test —** Show the slide for five seconds, then hide it. The audience representative states the message, evidence and intended action they remember.
5. **Record observations —** In A07-Peer-Coaching-and-Story-Review-Data.xlsx capture visible facts only: reading order, text size, labels, contrast, source, chart comprehension and action clarity.
6. **Ask clarifying questions —** The reviewer asks which audience, message, evidence and constraint drove the design. The designer answers without dismissing the observation.
7. **Apply the six-lens rubric —** Score Message, Data, Hierarchy, Accessibility, Story and Channel fit. Add one evidence note for every score.
8. **Prioritise one change —** Choose the issue with the largest audience or decision impact. State the change, owner and acceptance check.
9. **Revise the master —** Update the editable PPTX. Do not flatten the file or create an uncontrolled duplicate.
10. **Retest and reflect —** Repeat the five-second test and write 150-250 words on what improved, what remains and why.

**Test it**

| Generate the stakeholder mind map, then repeat the five-second audience test before and after revision. Record the observed change in recall, reading order or action clarity. |

| 2 min | Save reflection |

**Acceptance checklist**

* Feedback contains observations, not taste-only comments
* Every score has evidence
* One high-impact change is prioritised
* Revised PPTX remains editable
* Reflection explains how the change affects audience understanding

**Discussion and debrief**

* What did the audience understand first?
* Which issue has the greatest decision impact?
* Which feedback is evidence-based rather than taste?
* How will the change be tested?

**Debrief standard:** The review log contains observed evidence, a principle-based diagnosis, one prioritised change, a named owner and an acceptance check.

## Activity 8 — Create a Resource Scorecard Infographic

**Objective:** Compare infographic-tool investment options and recommend a resource plan using effectiveness and governance criteria.

**Output:** A weighted resource-scorecard infographic and one-page workflow recommendation (30 minutes).

**Scenario**

Northstar can fund one standard workflow for 12 staff. Options include PowerPoint templates only, PowerPoint with Microsoft 365 Copilot, a Copilot-first governed workflow, or a mixed approved workflow with PowerPoint as the controlled final-production layer.

Use the supplied budget workbook and effectiveness evidence to recommend a 12-month tool, training and governance plan aligned with business outcomes.

**Detailed step-by-step procedure**

2. **Confirm the business need —** Record the number of users, infographic volume, required channels, approved data classification and business outcome.
3. **Review total resource cost —** Check licence, training, production, review, governance, maintenance and estimated rework costs. Do not compare licence fees alone.
4. **Set decision weights —** Use the supplied weights or adjust them with a written rationale. Keep effectiveness and hard governance gates visible.
5. **Score each workflow —** Score PowerPoint templates, PowerPoint + Copilot, Copilot-first governed workflow and Mixed approved tools + PowerPoint using the same scale and evidence.

9. **Create the decision slide —** Open A08-Budget-and-Effectiveness-Decision-Start.pptx and add a native comparison chart, key trade-offs and one explicit recommendation.
